# Writing hooks

Craft, not rules the app enforces. Keep skills like this one about judgement —
the things a good writer knows and a prompt cannot fit.

## The job of a hook

A hook buys the second line. That is all it does. It does not summarise, it
does not introduce, and it does not promise value in the abstract.

## Four openings that work

- **The cost.** Name what the viewer is already losing. "You re-render every
  time you change one word."
- **The contradiction.** Say the true thing that sounds wrong. "The longer cut
  tested better."
- **The name.** Say who this is for, exactly. "If you edit on a laptop at
  midnight —"
- **The number, used once.** A specific figure beats a vague claim, but only
  the first time. "Three settings. Eleven minutes."

## Length

Under twelve words. Under eight is better. A hook that needs a comma usually
needs cutting instead.

## What to avoid

- Rhetorical questions the viewer cannot answer. "Ever wondered why?"
- Stacked adjectives. One does the work of three.
- Naming the format in the hook — "In this video", "Here's a quick tip".
- The word "actually". It is always doing nothing.

## Reading it back

Say it out loud at speaking pace. If you run out of breath, it is too long. If
you can hear where the music would come in, it is too written.
